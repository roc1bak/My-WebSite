# My WebSite

## Sobre o projeto

O My WebSite é um projeto de desenvolvimento web criado para praticar e aplicar conhecimentos de HTML e desenvolvimento de páginas web. O site reúne conteúdos acadêmicos, informações sobre tecnologia e materiais desenvolvidos durante atividades educacionais.

O projeto foi desenvolvido com foco na estruturação de páginas, organização de conteúdo e construção de uma experiência de navegação entre diferentes áreas do conhecimento.

## Tecnologias utilizadas

- **HTML5:** estruturação das páginas e organização do conteúdo.
- **CSS3:** estilização e personalização visual das páginas.
- **JavaScript:** utilizado quando necessário para adicionar funcionalidades e interatividade.

## Estrutura do projeto

O repositório contém páginas HTML organizadas por temas:

| Arquivo | Descrição |
|---|---|
| `projetofinal.html` | Página principal do projeto. |
| `meusgostos.html` | Página dedicada a gostos e interesses pessoais. |
| `CHS.HTML` | Conteúdos relacionados a Ciências Humanas. |
| `CNT.html` | Conteúdos relacionados a Ciências da Natureza. |
| `IOT.HTML` | Conteúdos relacionados à Internet das Coisas (IoT). |
| `LGG.html` | Conteúdos relacionados a Linguagens. |
| `MAT.HTML` | Conteúdos relacionados à Matemática. |

## Objetivos do projeto

- Praticar a criação e a estruturação de páginas com HTML.
- Desenvolver habilidades em desenvolvimento web.
- Organizar conteúdos acadêmicos em páginas temáticas.
- Aplicar conceitos de navegação e organização de informações.
- Consolidar conhecimentos adquiridos durante os estudos.
